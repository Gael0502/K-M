# K&M UI

A responsive K&M poultry marketplace and farm-business dashboard built with React, TypeScript, Vite, Tailwind CSS, Lucide React, React Router and Recharts.

## Run locally

1. Install Node.js 20.19+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite (usually <http://localhost:5173>).

Run `npm run build` to type-check and create the production frontend in `dist/`.

## Frontend demo

All content and workflows use local sample data in the browser. No sign-in, API, database, server, or real payment service is used. Cart and wishlist interactions are kept in React state for the current page session.

Included views:

- Public landing page, featured farms, categories, testimonials, and product marketplace.
- Search, category and price filters, sorting, product cards, wishlist, and shopping cart.
- Product detail and farmer profile pages.
- Farmer, buyer, delivery partner, and administrator dashboards.
- Interactive Recharts sales dashboards, buyer order tabs, delivery status demonstration, and admin user/product/order tabs.
- Checkout, address fields, delivery choices, and MTN Mobile Money, Airtel Money, and card payment option previews. Confirming checkout only displays a sample confirmation; it never collects payment information or charges money.
- Responsive mobile navigation and a farmer product-listing form demonstration.

The map, marketplace statistics, reviews, verification status, and order history are illustrative UI content. Product photography is loaded from Unsplash URLs.
